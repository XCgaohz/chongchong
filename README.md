# 🐛 虫虫大战 · 重制版


- **平台**：微信小游戏（Canvas 2D，零引擎零素材依赖）
- **开发调试**：任意浏览器直接玩（双端同一套代码）
- **联机**：好友房号对战（云开发同步），本机双标签页即可调试

---

## 玩法

| 模式 | 说明 |
|---|---|
| **闯关模式** | 3 虫小队 vs AI，无限关卡递进；每通一关**三选一强化卡**（12 种），战败进度清零、金币保留 |
| **热座对战** | 2~4 人传同一台手机轮流行动（同屏轮流行动） |
| **好友对战** | 创建 4 位房号 → 微信分享给好友 → 房号加入，1v1 实时对战 |
| **虫虫基地** | 金币解锁 4 种虫（蚂蚁/蜜蜂/甲虫/蜘蛛）、6 款帽子皮肤、4 项永久天赋 |

**操作**（触屏）：
- ◀ ▶ 移动 / ↑ 跳跃（蜜蜂可二段跳）
- 拖动屏幕任意处 = 瞄准；**长按"开火"蓄力，松手发射**
- 底部武器栏切换武器；"冲锋"按钮释放虫种专属技能（有冷却）
- 弹道受**重力 + 风力**影响；地形可被炸毁、可钻地道；掉进毒水直接淘汰

**武器**：火箭筒（∞）、弹跳手雷、霰弹枪、香蕉集束炸弹（裂成 5 枚）、钻头（挖隧道）、空袭（5 连投弹）、医疗包、神圣手雷（超级爆炸，补给箱限定）。

**虫种技能**：蚂蚁·冲锋 / 蜜蜂·振翅（加速+二段跳）/ 甲虫·虫壳护盾 / 蜘蛛·吐丝定身。

## 运行

### 浏览器（开发调试，最快路径）

```bash
cd web
node dev-server.js        # http://127.0.0.1:8124/web/index.html
```

打开后即可游玩全部模式。**联机调试**：同源开两个标签页，一边创建房间一边输入房号加入（走 BroadcastChannel，无需服务器）。

### 微信开发者工具

1. 打开「微信开发者工具」→ 导入项目 → 选择本目录
2. AppID：无 appid 时用"测试号"（`touristappid`）即可在模拟器运行**单机+热座**；真机预览需要你自己的 AppID
3. **好友在线对战**需要：
   - 注册小程序 AppID（个人免费），替换 `project.config.json` 中的 `appid`
   - 开通**云开发**（2025 起每个账号可免费创建一个云环境），创建集合 `cc_rooms`
   - 在开发者工具中逐个右键 `cloudfunctions/room-create|room-join|room-sync` →「上传并部署：云端安装依赖」
4. `js/net/netlayer.js` 会自动选择：有 `wx.cloud` 走云同步，否则浏览器走 BroadcastChannel

### 键盘（浏览器调试快捷键）

`←→` 移动 · `↑↓` 瞄准 · `W` 跳 · `空格` 长按蓄力/松手开火 · `1~8` 选武器 · `E` 技能 · `回车` 跳过回合

## 架构

```
game.js / game.json / project.config.json   微信小游戏包（touristappid 游客模式可跑）
js/
  platform.js        双端适配层（wx / 浏览器：canvas、触摸、存储、音频）
  main.js            App 主循环 + 场景管理
  core/              mathutil(确定性PRNG) terrain(位图破坏) camera particles audio input constants
  entities/          bug(物理+卡通渲染) projectile(弹道子步进)
  weapons/           8 种武器定义/弹种参数/图标绘制
  battle/battle.js   战斗核心：确定性指令驱动状态机（渲染/逻辑分离，联机只加壳）
  ai/controller.js   AI：行为状态机 + 弹道模拟评分 + 迭代弹道补偿
  meta/              species(虫种/技能/皮肤) upgrades(强化卡) progress(存档/天赋/金币) modes
  scenes/            home battle shop lobby
  ui/hud.js          HUD（队伍面板/计时/风向/武器栏/触控按钮）
  net/netlayer.js    联机抽象：BroadcastChannel(调试) / wx.cloud(正式) 自动切换
cloudfunctions/      room-create / room-join / room-sync（云函数，部署后支持真实好友对战）
web/                 index.html + dev-server.js（浏览器调试入口，禁缓存）
```

**联机同步策略**：回合同步指令（开火参数广播重放）+ 回合末虫子状态快照校正，漂移不跨回合累积；地形由相同 seed 生成 + 相同爆炸事件保持一致。

**确定性基础**：固定 1/60 逻辑步长 + mulberry32 种子随机，同类同版本 JS 浮点一致。
